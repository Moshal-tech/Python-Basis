## 🌟 Project Overview

This project was completed as part of **Week 6 of my Data Technician Bootcamp**, focusing on developing foundational Python programming skills through practical coding exercises and interactive applications.

These exercises strengthened my understanding of Python as a foundation for **data analysis, automation and business intelligence**.
